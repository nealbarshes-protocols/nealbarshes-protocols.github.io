# Daily Workflow 

NOTE: "pre-rounding" (i.e. starting data gathering, 

Sign-out from night intern: 6:00 AM 

Pre-op OR cases: OCL H&P updates, mark patients coming from home, complete pre-op checklist items 

Chart review for new data/updates 

Prepare wound care bucket, including the following basics:  
1. 4×4s  
2. ABD pads  
3. Adaptic and Xeroform  
4. Kerlix amd Webril
5. ACE wraps  
6. Medipore tape
7. suture removal kits
8. Doppler  
9. ultrasound gel  
10. marking pens  

Iodosorb, Santyl and other solutions should NOT be in the bucket. They need to be ordered for each patient under "Medications" and accompanied by a text order to request that it be kept at bedside. 


## After morning rounds, in order of priority:
1. Important orders first (consults, imaging, labs, discharges).
2. Communicate with other teams (Teams versus calling).  
3. Wound care not completed on rounds.  
4. Progress notes.
5. Pre-op checklists for pending OR patients.
6. Scrub into OR.
7. Sign out to night intern at 6:00 PM. Bring a printed list.

**Core rule**: Never keep critical information to yourself. Call the chief, fellow, or attending early. Honesty and closed-loop communication define a successful rotation.

# Writing ORDERS using CPRS

Order Iodosorb and Dakin's under Medications. Then put in a text order to have it at the patient's bedside. 


### Admission Orders 
Surgery Orders → Surgery Orders → Vascular Surgery Orders → Admit Patient 
Then complete the same detail flow as delayed admits 

Delayed Admission Orders 

Orders → Write Delayed Orders → “Admit to Vascular” (stay >48 h) or “Admit Observation Surgical” (stay <48 h) 

Suicide “No” → Source “Home MEDVAMC” → Treating Specialty “Vascular” → Attending “Staff MD” → Team “Red/Blue”→ Ward (floor: 5B or 5E, step-down: 5A, ICU: SICU or 5K) → diagnosis → condition → accept 

Select only home meds that should continue inpatient (ask seniors for help) 

Use the protocols website for full admission/pre-op/post-op order sets

# Placing Consults for other teams/services

### PICC Placement 
Orders → Consults/Procedures → IR/Neuro → Inpatient → IR CP INPT Procedures → PICC Insertion Order Set → complete remainder of orderset 
After placement: confirm tip at cavoatrial junction on CXR; then navigate to Patient Care → PICC Nursing Order Set  


### PT/OT Consult 
Orders → Consults/Procedures → PM&R → PM&R Inpatient OT/PT Menu → bottom “Click Here” → select both as needed 


### Limb Preservation / ID (Mindru) Consult 
Orders → Medicine → Infectious Disease → Infectious Disease Foot Infection/Limb Preservation INPT 
Message Dr. Mindru on Teams with details after placing consult
